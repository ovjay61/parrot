## ✨ 项目简介

**Parrot** 是一款专为私人媒体库打造的原生旗舰影音客户端，深度致敬 **iOS 液态玻璃（Liquid Glass）** 视觉语言与 **120Hz 物理弹簧交互**，在 Android 设备上还原通透磨砂层次、环境光折射与跟手阻尼体验。

## 🚀 核心特性

### 🎨 仿 iOS 液态玻璃与物理弹簧交互

- **动态环境光与玻璃折射**：自动采样当前海报主色调，呈现随内容流转的高透磨砂光影与高光描边。
- **一镜到底共享元素转场**：点击首页轮播或继续观看卡片，海报与片名 Logo 丝滑承接进入详情，返回自然回弹归位。
- **仿 iOS 长按浮层预览**：列表页长按任意海报即可呼出高透放大预览，松手自动归位，无需反复跳页。
- **横竖屏统一玻璃播控**：高透悬浮控制坞与紧凑胶囊按键，兼顾观影沉浸感与单手操控效率。

### 🎬 极客级双核播放能力

- **MPV + Media3 (EXO) 双核引擎**：默认免费开放高性能 MPV 引擎，支持硬解直出、HDR 色调映射、ASS 特效字幕、多音轨与在线字幕切换。
- **贴心播控手势**：支持长按倍速、双击快进退、自动跳过片头/片尾、锁屏防误触与 VR 优化播放。

### 🔎 多服务器管理与智能发现

- **全协议私人影库支持**：原生适配 **Emby**、**Jellyfin** 与 **飞牛影视**，支持多账号/多服务器一键切换。
- **全服务器聚合搜索 & 模糊搜索**：一键并发检索所有已添加服务器内容，支持模糊词容错匹配并跨服直达详情。
- **丰富元数据探索**：详情页聚合 TMDB / IMDb / 豆瓣评分、演职员、分类与工作室合集浏览，支持 Trakt 观影同步。
